How Door 2 decides

  
The agent's refund call is a proposal. Code works out from PayPal's records and the shop's order what is actually owed, then runs eight rules in order, in whole cents. The model never sets an amount.

  
    
    
  1. Identity. The order exists and belongs to this session.
    2. 
    
  2. Amount. Whole cents, never more than PayPal captured less what was already refunded.
    3. 
    
  3. Owed by the record. Overcharge, duplicate capture, cancelled before shipping.
    4. 
    
  4. Claim against the record. Not received is paid only when PayPal's tracker says cancelled or overdue.
    5. 
    
  5. Duplicates. Money already paid is not paid again.
    6. 
    
  6. Limits. One-refund cap.
    7. 
    
  7. Velocity. Daily cap per customer, reserved in the same step as the check.
    8. 
    
  8. Everything else goes to a person, with the evidence. An open PayPal dispute sends everything to a person.
