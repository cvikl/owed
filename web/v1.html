How Owed decides

  
The AI reads the message and asks for a refund through PayPal's own refund call on both sides. Behind Owed that call is only a request. Code works out from PayPal's records and the shop's order what is owed, then runs eight rules in whole cents. The AI never sets an amount. If the AI ends without asking, the model is asked once what the customer claimed, and if money was claimed the record settles what it proves.

  
    
    
  1. Identity. The order exists and belongs to this session.
    2. 
    
  2. Amount. Whole cents, never more than PayPal captured less what was already refunded.
    3. 
    
  3. Owed by the record. Overcharge, duplicate capture, cancelled before shipping.
    4. 
    
  4. Claim against the record. Not received is paid only when PayPal's tracker says cancelled or overdue.
    5. 
    
  5. Duplicates. Money already paid is not paid again.
    6. 
    
  6. Limits. One-refund cap.
    7. 
    
  7. Velocity. Daily cap per customer, reserved in the same step as the check.
    8. 
    
  8. Everything else goes to a person, with the evidence. An open PayPal dispute on the payment sends everything to a person.

For shops, and the limits

  

    
Owed keeps the refund interface of PayPal's Agent Toolkit, so an agent that already calls create_refund can route that call through the gate without its conversation layer being redesigned.

    
// before: the AI's refund call goes straight to PayPal
tools.create_refund = (input) => paypalToolkit.handleToolCall(call)

// after: the same call becomes a request, and Owed pays what PayPal's records prove
tools.create_refund = (input) => owed.gate({ order, askedCents, paypal, ledger, loadRecords, rules })

    
What this is not: a real deployment needs your order records, a way to tie a conversation to a customer and an order, your own limits, a durable database for the ledger and a queue for the cases that go to your staff. This demo is a single process with the ledger in memory and has only ever run on the PayPal sandbox. The benchmark is our own test suite on a PayPal stand-in; the arena and the race test are the live sandbox evidence.
